Data Quality Dimensions

📊 Completeness

Definition: Are all required data points present?

Customer ID Name Email Phone Status
C001 John Doe john@email.com NULL Active
C002 Jane Smith NULL 555-0123 Active
C003 Bob Wilson bob@email.com 555-0456 Active

Testing Checklist:

  • Count NULL/empty values per column
  • Check required fields in forms
  • Verify all records have primary keys
  • Check for default/placeholder values

🔄 Consistency

Definition: Is data uniformly formatted and following rules?

Order ID Date Amount Currency
O1001 2024-03-15 150.00 USD
O1002 15/03/2024 $200.00 USD
O1003 March 15, 2024 300 usd

Testing Checklist:

  • Validate date formats (ISO 8601 preferred)
  • Check currency codes (ISO 4217)
  • Verify email format patterns
  • Ensure consistent capitalization
  • Check referential integrity between tables

⚖️ Bias Detection

Definition: Systematic skew in data representation

Applicant ID Gender Experience (years) Education Level Hired (Yes/No)
A001 Male 5 Masters Yes
A002 Male 3 Bachelors Yes
A003 Female 7 PhD No
A004 Female 4 Masters No

Bias Detection Metrics:

  • Disparate Impact Ratio: (Female hire rate) / (Male hire rate)
  • Statistical Parity: Equal selection rates across groups
  • Representation Check: Does sample match population?
